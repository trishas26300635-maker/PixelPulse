# VisionCraft

VisionCraft is a responsive, web-based image search application designed to give users an effortless visual discovery experience.

## Features & Design Decisions
1. **Clear Control**: Added a clear button inside the search form to allow users to instantly reset the search field.
2. **Category Suggestions**: Included quick-pick category chips (Nature, Architecture, Animals, Technology) so users can explore common topics with a single click[cite: 1].
